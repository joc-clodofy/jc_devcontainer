Manual: Registro Amazon SP-API (Solution Provider Portal) + Odoo con amazon_wiap

Objetivo: Integrar la cuenta vendedor de Amazon con Odoo 17 usando sale_amazon + amazon_wiap, sin el proxy IAP de Odoo Enterprise, con datos reales de la propia empresa.
Tipo de integración: App privada, auto-autorizada, en estado Draft (no requiere publicación en el Appstore).

Requisitos previos

RequisitoDetalle
Cuenta AmazonProfessional Seller en Seller Central (no Individual)
UsuarioPrimary User de la cuenta vendedor
OdooMódulos sale_amazon (Enterprise) + amazon_wiap instalados
URL públicaOdoo accesible por HTTPS; callback: https://tu-dominio.com/amazon/return
Perfil desarrolladorAprobado por Amazon antes de usar la API con datos reales

FASE 1 — Perfil de desarrollador (Developer Profile)

1.1 Acceso al portal

  1. Entrar en Solution Provider Portal con las credenciales de Seller Central.
    (Si aún no habéis migrado: Seller Central → Apps and Services → Develop Apps.)
  2. Ir a Settings → Developer Profile (o completar el formulario al entrar en Develop Apps).

1.2 Datos del formulario

CampoValor recomendado
Data AccessPrivate Developer: I build application(s) that integrate my own company with Amazon Services APIs
Contact InformationDatos reales de la empresa
Use CasesGestión interna de pedidos, inventario FBM/FBA y catálogo de nuestra cuenta vendedor en nuestro ERP (Odoo). Integración exclusiva para uso propio.
Security ControlsRespuestas honestas sobre almacenamiento seguro, acceso restringido, cifrado, etc.

1.3 Roles en el perfil de desarrollador (sección Sellers)

Marcar los mismos que usará la app:

  • Inventory and Order Tracking
  • Amazon Fulfillment
  • Product Listing
  • Pricing

1.4 Envío y espera

  1. Aceptar Solution Provider Agreement, AUP y Data Protection Policy.
  2. Pulsar Register.
  3. Esperar aprobación por email (responder en 5 días si piden más información).
Sin perfil aprobado, la app puede crearse pero las llamadas API pueden devolver 403.

FASE 2 — Crear la aplicación SP-API

2.1 Registrar la app

  1. En Solution Provider Portal: Add new app client (o Registrar nueva aplicación).
  2. Completar el formulario:
CampoValor
NombreEj.: Odoo 17 Integración
API typeSelling Partner API (SP-API)
Application typeProduction (no Sandbox)
Importante: Sandbox sirve para datos de prueba ficticios y endpoints distintos. Odoo usa endpoints de producción; para pedidos y stock reales hay que elegir Production.

2.2 Business entities supported

Marcar solo: Sellers

No marcar: Amazon Business, Freight, Shipping, Vendors (salvo que el cliente sea vendor en Vendor Central, caso excepcional).

2.3 Roles de la aplicación (sección Sellers)

RolMarcar
Inventory and Order TrackingSí
Amazon FulfillmentSí
Product ListingSí
PricingSí

No marcar: Selling Partner Insights, Buyer Communication, Buyer Solicitation, AWD (salvo uso explícito de AWD).

2.4 Delegación PII (RDT)

Pregunta: Will you delegate access to PII to another developer's application?

Respuesta: No

Odoo consume el PII directamente; no se delega a otra app de un tercero.

2.5 Campo IAM Role ARN

No aparece en el formulario actual — es normal. La guía antigua que decía “dejarlo vacío” ya no aplica; Amazon usa autenticación LWA sin IAM en este flujo.

2.6 Guardar

  1. Save and exit.
  2. La app queda en estado Draft — correcto para integración privada.

FASE 3 — Obtener credenciales

  1. En la lista de aplicaciones, localizar la app creada.
  2. Pulsar View credentials / Ver credenciales.
  3. Guardar en lugar seguro:
Credencial AmazonUso en Odoo (amazon_wiap)
Application ID (amzn1.sp.solution.xxx...)Amazon Application ID
Client ID (LWA)LWA Client ID
Client Secret (LWA)LWA Client Secret
No hace falta publicar la app en el Appstore ni solicitar listing público.

FASE 4 — Configuración en Odoo

4.1 Ajustes generales

Ajustes → Ventas → Amazon Connector → Amazon WIAP

Campo OdooValor
Amazon Application IDApplication ID de Amazon
LWA Client IDClient ID
LWA Client SecretClient Secret
Authorize in Beta (Draft app)Activado

El flag Beta añade version=beta en la URL OAuth mientras la app esté en Draft.

4.2 Crear cuenta Amazon en Odoo

  1. Ventas → Amazon → Cuentas Amazon (o menú del módulo WIAP).
  2. Nueva cuenta: nombre, marketplace base (ej. España → EU), empresa, almacén FBA si aplica.
  3. Guardar.

FASE 5 — Autorización OAuth

  1. En la ficha de la cuenta, pulsar Autorizar / Connect with Amazon.
  2. Redirección a Seller Central → iniciar sesión como Primary User → aceptar permisos.
  3. Vuelta a Odoo en https://tu-dominio.com/amazon/return.
  4. Si todo va bien: refresh_token guardado y marketplaces disponibles para sincronizar.

Qué hace amazon_wiap en este paso

  • Usa vuestra Application ID (no la de Odoo S.A.).
  • Intercambia el código OAuth directamente con Amazon LWA (sin iap-services.odoo.com).
  • Con app en Draft, envía version=beta si el checkbox está activo.

Resumen ejecutivo

El cliente necesita una app privada de tipo Production en Draft, con perfil de desarrollador aprobado como Private Developer y los cuatro roles de Sellers. Con las credenciales en Odoo y una autorización OAuth con beta activado, el conector funciona con datos reales sin pasar por el proxy IAP de Odoo ni publicar en el Appstore de Amazon.
